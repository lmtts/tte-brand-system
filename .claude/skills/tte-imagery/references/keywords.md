# TTE Keyword Library — Sourcing & Search Reference

Use these keywords to find TTE-aligned imagery on stock libraries, inspiration platforms, and photographer archives. Keywords are grouped by intent. Click or copy any keyword directly into your search field.

When building a search query, combine one keyword from each relevant category:
**[Photographer/Style] + [Environment] + [Subject] + [Aesthetic]**

Example: `"Steve McCurry" + "Central Asia" + "woman portrait" + "golden hour"`

## 07 — Platform-Specific Search Tips

### Getty Images / iStock
Use filters: **Editorial** (not commercial) + **Documentary** style
Combine: `[ethnicity/region] + [activity] + [environment]`
Example: `"Central Asian woman" + "prayer" + "mountain village"`

### Unsplash / Pexels
Search style terms directly: `"golden hour silhouette mountain"`, `"analog film grain portrait"`
Best for: Layer 1 Scale shots and POV atmospheric shots

### Stocksy United
Premium, editorial-quality. Best for: Layer 2 Stillness — dignified portrait work
Search: `"documentary portrait"`, `"environmental portrait"`, `"authentic travel"`

### Behance
Search: `"expedition photography"`, `"Steve McCurry style"`, `"humanitarian photography"`
Filter by: Photography category

### Are.na
Channels to explore: `expedition photography`, `magnum photos`, `documentary portrait`, `cinematic still`

### Pinterest
Search: `"NatGeo photography style"`, `"earthy film grain portrait"`, `"Chris Burkard landscape"`
Pin boards to follow: National Geographic photography, Magnum Photos, VII Photo Agency

### Google Images
Reverse-search existing TTE images to find visual siblings
Search: `Steve McCurry + [country] + portrait` for Stillness layer references

## 08 — Negative Keywords
*Add these as exclusions (use `-` prefix in most platforms or "NOT" in boolean search)*

Use to filter out off-brand results:

```
-"stock photo" -smile -posed -"ring light" -"church media" 
-"soft focus" -HDR -"lens flare" -"poverty tourism" 
-"mission trip" -"charity" -influencer -"studio backdrop"
-"donation appeal" -generic -"gradient background"
```

### Midjourney Negative (--no flag)
```
--no lens flare, soft glow, stock smile, ring light, church media, HDR, gradient, studio backdrop, poverty framing, influencer, AI smooth skin
```

### Specific Platform Exclusions
- Getty: Filter out "RF" (Royalty-Free stock) — prefer "Editorial" use type
- Unsplash: Exclude via `-happy` `-smile` `-studio` in search
- Pinterest: Exclude by blocking specific boards that surface mission-trip clichés
